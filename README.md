# 건강 대시보드 (HealthDashboard)

애플워치와 아이폰이 **건강(HealthKit)** 에 기록한 정보를 한 화면에서 볼 수 있는 iPhone 앱입니다.
SwiftUI + HealthKit + Swift Charts로 만들었고, 건강 데이터는 기기 밖으로 보내지 않습니다. (직접 기록한 식단만 건강 앱에 저장)

## 볼 수 있는 정보

| --- | --- |

- **AI 건강 코치** (iOS 26+, Apple Intelligence): 내 준비 점수·수면·심박·활동·복약·습관·날씨를 근거로 질문에 답하는 채팅.
  아이폰 안의 모델(Foundation Models)만 사용해 데이터가 밖으로 나가지 않음
- **식단 기록**: 📸 사진 한 장(한상차림을 음식별로 나눠 칼로리·탄단지·당·나트륨 추정, iOS 27+), ✍️ 말하듯 입력
  ("점심에 김치찌개랑 밥 반 공기"), 🏷 영양성분표 촬영, 직접 입력, 자주 먹는 음식 원탭 추가. AI 추정값은 저장 전에 확인·수정.
  기록은 앱 안(Documents/meals.json + 사진)에 계속 보관되고 **애플 건강 앱에도 '음식' 기록으로 저장**됨.
  먹은 칼로리 vs 쓴 칼로리(워치), 단백질 목표(체중×1.2g, 운동한 날 1.6g), 최근 7일 차트.
  야식·술은 습관 기록에 자동 반영, AI 코치·주간 리포트·습관 분석·컨디션 리포트가 모두 식단 기록을 활용

  - 이번 주 저녁 계획: 가족 캘린더에 '🍽 메뉴' 일정으로 저장 → 배우자 캘린더에도 자동 표시

  - 냉장고로 추천: 재료를 적거나(iOS 26+) 냉장고 사진(iOS 27+)으로 오늘 저녁 메뉴 3가지

    ("건강 대시보드 물 마셨어", "약 먹었어", "오늘 컨디션 어때", "오늘 저녁 메뉴 뭐야")

  - AI 코치: 실시간 답변 · 대화 저장 · 음성 질문, 아이폰 모드(워치 없는 배우자용), 즐겨찾기 음식 고정

  최대 90일 기록을 직접 조회해서 답함 (14일 초과는 주 단위 평균으로 요약)
- **AI 주간 리포트**: 월요일에 지난주(월~일)를 그 전주와 비교해 총평·잘한 점·아쉬운 점·이번 주 목표를 AI가 작성해 알림 (AI 코치 탭 › 주간 리포트)
- **가족 캘린더**: 애플 캘린더(EventKit)와 연동. 가족 공유의 '가족' 캘린더를 자동으로 찾아 월 달력으로 보여주고,
  애플 기본 편집 화면으로 일정 추가·수정(반복·알림·초대 지원). 추가한 일정은 가족 모두의 캘린더 앱에 동기화.
  대시보드에 '오늘의 가족 일정' 카드
- **컨디션 이상 조기 경보**: 수면 중 심박수↑ · HRV↓ · 손목 온도↑ · 호흡수↑ 신호가 겹치면 대시보드 카드 + 하루 한 번 알림
- **습관 기록 · 분석**: 술·오후 카페인·야식·야근·스트레스·늦은 스마트폰·낮잠을 기록하면, 기록한 날과 아닌 날의
  다음 날 준비 점수 / 그날 밤 수면 / 다음 날 HRV 차이를 보여줌 (11시 전 취침·운동한 날은 자동 분석)
- **현재 위치 자동 지역**: 은평구·소공동·평택 중 지금 가장 가까운 곳으로 추천·알림·위젯 날씨가 자동 전환
  (앱을 열 때 위치 확인, 위치는 기기 밖으로 보내지 않음)
- **오늘의 운동 추천**: 준비 점수 + 기본 지역 날씨·미세먼지를 합쳐 야외/실내 운동과 강도를 추천
- **컨디션 리포트 알림**: 정한 시각에 준비 점수, 요소별 상태, 지난밤 수면, 안정 시 심박, 어제 활동, (선택) 날씨·운동 추천
- **복약 알림**: 약 이름과 시각을 정해 매일 알림 (기본: 탈모약 오후 9시). 알림에서 바로 "복용 완료" / "30분 뒤 다시",
  대시보드에서 오늘 복용 체크와 최근 7일 기록
- **위젯**: 오늘 한눈에(준비 점수·추천·날씨), 활동 링, 날씨(지역 선택 / 중간 크기는 세 지역) — 홈 화면·잠금 화면.
  워치 데이터가 들어오면 앱이 백그라운드에서 갱신하고(HealthKit 백그라운드 전달, 보통 최대 1시간 간격) 위젯에 갱신 시각을 표시
- **대시보드 편집**: 섹션 순서 변경·숨기기, 즐겨찾기 지표 (카드를 길게 눌러도 추가/제거)
- **날씨 탭**: 서울 은평구 · 중구 소공동 · 평택의 현재 날씨, 시간별(24시간) · 7일 예보, 미세먼지/초미세먼지, 자외선, 일출·일몰
  ([Open-Meteo](https://open-meteo.com) 무료 API 사용, API 키 불필요)
- 각 지표 카드를 누르면 **7 / 30 / 90일 추세 차트**와 평균·최저·최고가 나옵니다.
- 걸음 수처럼 쌓이는 값은 "오늘 합계", 심박수처럼 측정하는 값은 "가장 최근 측정값"을 보여줍니다.
- 기록이 없는 항목은 기본적으로 숨기며, 설정에서 모두 표시할 수 있습니다.
- 시뮬레이터에서 화면을 확인할 수 있도록 **샘플 데이터 모드**가 있습니다.

## 준비 점수에 대해

애플워치 Series 12(watchOS 27)의 공식 **준비 점수(Readiness)** 는 HealthKit으로 다른 앱에 제공되지 않습니다.
그래서 이 앱은 같은 입력값을 최근 30일 개인 기준선과 비교해 직접 추정합니다 (`Models/Readiness.swift`).

| 요소 | 가중치 | 좋은 방향 |
| --- | --- | --- |
| 수면 중 심박 변이 (RMSSD 우선, 없으면 SDNN) | 30% | 평소보다 높을수록 |
| 수면 (지난밤 수면 시간, 깊은+렘 수면 비율) | 30% | 8시간에 가까울수록 |
| 수면 중 평균 심박수 | 20% | 평소보다 낮을수록 |
| 운동 부하 (최근 7일 ÷ 4주 평균 활동 에너지) | 10% | 급격히 늘지 않을수록 |
| 야간 활력 징후 (손목 온도, 호흡수) | 10% | 평소 범위일수록 |

심박 변이와 심박수는 애플처럼 **잠든 시각~깬 시각 사이의 평균**을 씁니다. 워치를 차고 잔 기록이 1주일 미만이면
하루 평균 HRV와 안정 시 심박수로 대신합니다. 기록이 없는 요소는 빼고 나머지로 계산하며, 수면이나 HRV 중 하나는 있어야 점수를 냅니다. 의료용이 아닌 참고용 지표입니다.

## 처음 한 번: 서명 설정 파일 만들기

위젯과 앱이 데이터를 공유(App Group)하려면 번들 ID와 팀이 고정되어 있어야 합니다.
`Configs/Local.xcconfig` 파일을 만들고 두 줄을 적어 두면, `xcodegen generate`를 다시 해도 서명 설정이 유지됩니다.

```bash
# 팀 ID 확인 (Xcode에서 Team을 한 번 선택해 둔 프로젝트가 있을 때)
grep -m1 DEVELOPMENT_TEAM HealthDashboard.xcodeproj/project.pbxproj

# Local.xcconfig 만들기 (값은 본인 것으로)
printf 'DEVELOPMENT_TEAM = ABCDE12345\nBUNDLE_ID_PREFIX = com.myname\n' > Configs/Local.xcconfig
```

앱 번들 ID는 `<BUNDLE_ID_PREFIX>.healthdashboard`, 위젯은 `<BUNDLE_ID_PREFIX>.healthdashboard.widgets`,
App Group은 `group.<BUNDLE_ID_PREFIX>.healthdashboard`로 자동 설정됩니다.

## 빌드 방법 (Mac 필요)

1. Xcode 15 이상 설치 (iOS 17 이상 대상)
2. [XcodeGen](https://github.com/yonaskolb/XcodeGen) 설치 후 프로젝트 생성
   ```bash
   brew install xcodegen
   cd <저장소 폴더>
   xcodegen generate
   open HealthDashboard.xcodeproj
   ```
3. 위의 `Configs/Local.xcconfig`를 만들었다면 서명은 자동으로 설정됩니다.
   (만들지 않았다면 `HealthDashboard`와 `HealthWidgets` 두 타깃 모두 Signing & Capabilities에서 Team과 번들 ID를 지정)
4. 아이폰을 연결하고 실행(⌘R) → 처음 실행 시 **"건강 데이터 연결하기"** 를 눌러 읽기 권한을 허용

> 실제 데이터는 **실기기**에서만 보입니다. 시뮬레이터에서는 "샘플 데이터로 둘러보기"를 사용하세요.
> 이미 권한을 거부했다면 설정 앱 › 건강 › 데이터 접근 및 기기 › 건강 대시보드에서 다시 켤 수 있습니다.

## 지표 추가하기

`HealthMetric.all` 배열에 한 줄을 추가하면 권한 요청, 대시보드 카드, 추세 차트에 자동으로 반영됩니다.

```swift
HealthMetric(id: .distanceSwimming, title: "수영 거리", symbol: "figure.pool.swim", category: .activity,
             unit: .meter(), unitLabel: "m", aggregation: .cumulative)
```

## 가족과 함께 쓰기

**가족 캘린더**: 아이폰 설정 › [내 이름] › 가족 공유를 설정하면 iCloud에 '가족' 캘린더가 자동으로 생기고
가족 구성원 모두의 캘린더 앱에 나타납니다. 이 앱은 그 캘린더를 자동으로 찾아 읽고 씁니다.
가족 공유를 쓰지 않는다면 앱에서 iCloud '가족' 캘린더를 만든 뒤, 캘린더 앱 › 캘린더 › ⓘ › 사람 추가로 가족을 초대하세요.

**앱 설치 (가족 아이폰)**: App Store에 올린 앱이 아니라서 애플 '가족 공유(구입 항목 공유)'로는 나눌 수 없습니다.

| 방법 | 비용 | 특징 |
| --- | --- | --- |
| 가족 아이폰을 맥에 연결해 Xcode로 설치 | 무료 | 7일마다 다시 설치 필요, 기기 등록 수 제한 |
| Apple Developer Program + **TestFlight** | 연 $99 (약 13만 원) | 가족에게 초대 메일/링크 → TestFlight 앱으로 설치, 빌드당 90일 사용 |
| App Store 출시 + 가족 공유 켜기 | 연 $99 + 심사 | 가족 공유로 자동 공유, 가장 편함 |

건강 데이터는 각자 자기 아이폰의 건강 앱 데이터만 읽습니다 (가족끼리 건강 데이터는 공유되지 않음).

## 무료 계정의 7일 기한 (자동 재설치)

무료 Apple ID로 설치한 앱은 애플 정책상 서명 허가증이 **7일** 뒤 만료되어 열리지 않습니다. (기록은 지워지지 않음)
유료 개발자 프로그램(연 $99)이면 1년이고 TestFlight도 쓸 수 있습니다. 무료로 계속 쓰려면 아래처럼 자동화하세요.

1. 아이폰을 케이블로 한 번 연결한 뒤 Xcode › Window › Devices and Simulators에서 **Connect via network** 체크 (부부 아이폰 모두)
2. 터미널에서 프로젝트 폴더로 이동해 한 번만:
   ```sh
   ./scripts/reinstall.sh               # 지금 바로 두 폰에 다시 설치 (테스트)
   ./scripts/setup-auto-reinstall.sh    # 매일 23:30 자동 재설치 켜기 (끄기: off)
   ```
3. 그 시각에 Mac이 켜져 있고(잠자기면 깨어날 때 실행) 아이폰이 같은 와이파이에 있으면, 기한이 매일 7일로 다시 늘어납니다.
   연결 안 된 폰은 건너뛰고 다음 날 다시 시도해요. 로그: `~/Library/Logs/HealthDashboardReinstall.log`

앱 안에서도 만료 하루 전 저녁 8시에 알림이 오고, 2일 이하로 남으면 건강 탭 맨 위에 안내가 보입니다. (설정 › 정보 › 앱 사용 기한)

## 우리집 건강 웹사이트 (시놀로지 NAS)

앱 대신 NAS에서 돌아가는 웹사이트 버전입니다. 준비 점수, 식단, 가족 식탁, iCloud 캘린더, 아이패드 전광판을
사파리로 쓰고 모든 기록을 MariaDB에 저장합니다. 설치 방법은 [family/README.md](family/README.md).

## 아침 브리핑의 한계

iOS는 앱을 정해진 시각에 정확히 실행해 주지 않습니다. 그래서 앱이 실행될 때마다(직접 열거나, iOS가 백그라운드로 깨울 때)
앞으로 7일치 알림을 그때 알고 있는 최신 정보로 다시 예약합니다.
날씨는 예보라 미리 알 수 있지만, 준비 점수는 그날 아침 데이터가 필요하고 잠긴 상태에서는 건강 데이터를 읽을 수 없어,
그날 점수가 아직 없으면 알림에 "앱을 열면 계산해요"라고 표시됩니다.
